## 2026-07-20 - [Sentinel] Fix new Function injection
**Vulnerability:** A `new Function` constructor was being called dynamically via `createFn` inside `packages/engine/src/services/analysis/JITCompiler.ts`. While the `args` parameters were sanitized correctly, the `body` code (dynamically generated source code representing mathematically compiled models) was not fully sanitized before compilation, opening the risk for script injection when creating analytical simulation loops.
**Learning:** This repo has a `safeFunctionCompiler.ts` that includes a `createCompiledFunction` wrapper that warns about CodeQL/AST validation but also performs an identifier validation check on arguments and correctly builds the function natively. The underlying CodeQL alerts check if dynamic functions exist locally and the `JITCompiler.ts` was bypassing the shared standard!
**Prevention:** Always rely on `createCompiledFunction` over direct `new Function()` invocations, ensuring that CodeQL and shared utilities evaluate the risk vectors.
