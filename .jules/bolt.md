## 2024-06-24 - Zero-Allocation Tokenization for Hot Path Expression Evaluation
**Learning:** In the engine simulation `SimulationLoop` and `NetworkExpansion`, hot paths repeatedly check if reaction rate expressions are dependent on observables, parameters, or functions (`isFunctionalRateExpr`). Currently, this is achieved via an AST traversal (`getExpressionDependencies`) using an ANTLR parser, which parses every rate expression dynamically. This approach creates significant CPU and GC overhead. An imperative character scanning approach (`charCodeAt`) is highly effective for identifying identifiers while avoiding string allocation, array instantiation, or regex execution.
**Action:** Replace `getExpressionDependencies` usage in `isFunctionalRateExpr` with an imperative character scanning loop, preserving exactly the same behavior.
